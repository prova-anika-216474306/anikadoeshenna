# Anika Does Henna

A one-page site: photo gallery with prices and a Book on WhatsApp button.

## Add a photo
1. Put the new picture in the `images` folder (about 800x1000 px, portrait, e.g. `11.jpg`).
2. Open `photos.js`, copy one line, paste it at the top of the list, and change `file`, `alt`, `price` and `note`.
   - `price`: `"$20"` or `"Message for price"`
   - `note`: `"per side per hand"` (or `""` for none)

## Change other text
Open `index.html` and edit the text (name, services, WhatsApp number in the green button link).

## Publish on GitHub Pages
Repo > Settings > Pages > Deploy from a branch > `main` / root > Save.
